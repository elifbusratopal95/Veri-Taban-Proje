# Veritabanı Yönetimi Projesi — Hayvan Sahiplendirme Platformu

İnsanların sahiplendirmek istedikleri hayvanları sisteme ekleyebildiği ve sahiplenmek istedikleri hayvanları inceleyerek başvuruda bulunabildiği bir web platformudur.
Projenin temel amacı, hayvan sahiplendirme sürecini daha düzenli ve kolay bir şekilde yönetebilecek bir sistem oluşturmaktır.
